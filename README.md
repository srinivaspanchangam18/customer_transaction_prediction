# Customer Transaction Prediction

## Project Overview

This project focuses on customer transaction prediction using machine learning techniques. It demonstrates a structured approach to data preparation, exploratory data analysis, feature engineering, predictive modelling, and model evaluation.

The goal is to explore customer transaction data and develop predictive models to identify patterns that can support data-driven decision-making.

## Objectives

- Explore and understand customer transaction data.
- Perform data cleaning and preprocessing.
- Prepare relevant features for machine learning.
- Develop predictive models.
- Evaluate model performance using appropriate metrics.
- Understand patterns in the data through exploratory analysis.

## Technologies Used

- **Programming Language:** Python
- **Data Analysis:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-learn
- **Development Environment:** Jupyter Notebook

## Project Workflow

1. **Data Loading:** Import the dataset and inspect its structure.
2. **Exploratory Data Analysis:** Examine distributions, patterns, and data quality.
3. **Data Preprocessing:** Handle missing values, data types, and other preprocessing requirements.
4. **Feature Engineering:** Prepare relevant features for modelling.
5. **Model Development:** Train the predictive models implemented in the notebook.
6. **Model Evaluation:** Evaluate the models using appropriate performance metrics.
7. **Interpretation:** Review the results and identify potential insights.

## How to Run the Project

### 1. Clone the Repository

```bash
git clone <YOUR-REPOSITORY-URL>
cd customer-transaction-prediction
```

### 2. Create a Virtual Environment

```bash
python -m venv .venv
```

Activate it on Windows:

```bash
.venv\Scripts\activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Prepare the Dataset

Place the authorized dataset in your local `data/` directory. Update the file path in the notebook if necessary.

The dataset is not included in this repository. Do not publish private or restricted customer transaction records without permission.

### 5. Run the Notebook

```bash
jupyter notebook
```

Open `CUSTOMER_TRANSACTION_PREDICTION.ipynb` and execute the cells in sequence.
